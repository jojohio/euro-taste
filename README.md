# Euro Taste Rebuild v8

Version 1.6.0 adds a complete DE / EN / PT translation system.

Translated content includes:
- Header, menu, navigation and footer
- Hero and country sections
- Filters, cards and project copy
- Country names
- Recipe subtitles, descriptions, servings, time and type
- Every ingredient in original and vegan variants
- Every preparation step
- Preparation and serving notes
- Progress labels, buttons and accessibility labels

The selected language is stored in localStorage and stays active while navigating.

## Start
```bash
npm install
npm run dev
```
